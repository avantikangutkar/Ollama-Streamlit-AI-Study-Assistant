AI Study Assistant Using Ollama and Streamlit



A beginner-friendly AI question-answering application built using Ollama, Llama 3.2, Python, and Streamlit.



Project Overview



The AI Study Assistant allows users to enter questions and receive AI-generated responses from a locally running Llama 3.2 language model.



The application uses Ollama to run the AI model locally and Streamlit to provide a simple interactive web interface.



Technologies Used



\- Python 3.13.13

\- Ollama

\- Llama 3.2

\- Streamlit

\- Ollama Python Client
